<h1>Mitti Studio - Responsive Landing Page</h1>

<p>
  A responsive pottery studio landing page built with HTML5, CSS3,
  and vanilla JavaScript for YuvaIntern Week 1.
</p>

<h2>Technologies Used</h2>

<ul>
  <li>HTML5</li>
  <li>CSS3</li>
  <li>JavaScript</li>
</ul>

<h2>Features</h2>

<ul>
  <li>Responsive design for mobile, tablet, and desktop</li>
  <li>Mobile navigation menu</li>
  <li>Responsive layouts using Flexbox and CSS Grid</li>
  <li>Interactive email signup form</li>
  <li>Accessible and semantic HTML structure</li>
</ul>

<h2>Project Files</h2>

<ul>
  <li><strong>index.html</strong> - Page structure and content</li>
  <li><strong>css/style.css</strong> - Styling and responsive layouts</li>
  <li><strong>js/main.js</strong> - Navigation, form validation, and interactions</li>
</ul>

    View Mitti Studio

</p>
