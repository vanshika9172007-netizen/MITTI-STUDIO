# Mitti Studio - Responsive Landing Page (YuvaInter, Week 1)

Semantic HTML5, mobile-first CSS (Flexbox + Grid), vanilla JavaScript.

## Files
- index.html - page structure (header, nav, hero, features, process, sign-up, footer)
- css/style.css - styles and media queries (700px tablet, 900px desktop)
- js/main.js - menu toggle, scroll header shadow, form validation

## Run
Open index.html in any browser. No build step or dependencies.
